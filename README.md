# GiftStudio
Virtual Cast向けギフト・エフェクトVCI作成ツール
ギフトに反応して3Dオブジェクトが落ちてくるVCIを作成しよう！

[最新版をダウンロード](https://github.com/oyudot/GiftStudio/releases/latest)

## 配信概要欄への記載例
この配信では、ニコ生ギフトに反応して、VR空間に3Dモデルが降る独自演出を使用しています。金額によってモデルの種類やサイズが変わる場合があり、候補が複数ある場合は等確率でランダムに選ばれます。

Vギフトとは異なる一時的な演出で、賞品やモデルデータの提供はありません。特定のモデルの出現や、通信・動作状況による演出の表示は保証されません。ギフトの送信は任意です。
